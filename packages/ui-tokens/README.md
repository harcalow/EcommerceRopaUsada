# @perchados/ui-tokens

Tokens de marca compartidos por web y mobile.

## Propósito
Una sola definición de la identidad visual para ambas plataformas.

## Qué contiene
- Colores, tipografía, radios y espaciados.

## Quién lo usa
- `apps/web` y `apps/mobile`.

## Reglas
- ✅ Los estilos consumen tokens; los valores se definen solo aquí.
- ✅ Los colores respetan contraste AA (ADR-006).
- ❌ No usar valores literales de color o espaciado en las apps.

## Capa en que se rellena
001 (base técnica), a partir del mockup de Perchados.
